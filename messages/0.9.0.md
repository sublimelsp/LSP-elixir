=> 0.9.0

## Breaking changes

The name of the language server session has changed from `lsp-elixir` to `LSP-elixir`.

If you override the server settings in a `.sublime-project` file, rename the key to keep them applied:

```js
{
  "settings": {
    "LSP": {
      "LSP-elixir": { // previously "lsp-elixir"
        "settings": {
          // ...
        }
      }
    }
  }
}
```

Settings in `Preferences: LSP-elixir Settings` aren't affected.
